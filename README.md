# Kuizi Historik – 28–29 Nëntori

Kuiz interaktiv për Pavarësinë (28 Nëntor 1912) dhe Çlirimin e Shqipërisë (29 Nëntor 1944).

- 48 pyetje me alternativa dhe shpjegim pas çdo pyetjeje
- Hartë interaktive e ngjarjeve kryesore (1878–1944)
- Lojë individuale ose gara me 2–6 grupe në një laptop
- Gjatësia e lojës dhe koha për pyetje sipas zgjedhjes
- Tinguj, numërim 3-2-1, podium dhe renditje në fund
